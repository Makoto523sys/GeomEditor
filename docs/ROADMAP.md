# 開発計画

目的はメッシュ前処理用の幾何編集。解析メッシュ生成、ソルバー、応力分類は範囲外。

## 初期実装で用意した基盤

CADカーネルによるB-rep読込・編集・書出し、HTML/WebGL画面、モデル選択、面分割/ソリッド分割の区別、共有境界、トランザクション、形状検査、保存復元。

## 1. 実形状と操作性の受入

- Windows 11実機での導入・起動・WebGL表示試験。
- タンク脚の曲面・アール終端を含む機密のない試験形状で、評価ラインの位置を照合。
- 水位分割STEPをSalome等で読み、境界の保持と節点適合を確認。
- 面/エッジの選択候補リスト、背面選択の切替、表示上の座標軸、ID表示。
- 分割プレビューを平面表示から実交線表示へ拡張。

## 2. 評価ライン作成の強化

- CAD頂点、エッジパラメータ、最近接点に基づく厳密なスナップ。
- 3点平面、既存面から距離指定した平行平面、座標系指定。
- 曲線・複数点スプラインを工具とする分割、曲面法線方向の投影。
- 曲線エッジ基準の接線・法線・平行オフセット。
- カーネルの変更履歴に基づく面/エッジの永続名、評価ライン群の保存。

## 3. サーフェイス修復の強化

- 選択エッジの置換・局所縫合・切離し。
- 曲面の延長・untrim・トリム領域の変更。
- 非平面ループの穴埋め、接線連続性の指定。
- 接続を保つ面群オフセット・面の置換。
- 小面/短エッジ/穴/フィレットの自動探索と簡略化。
- メッシャー連携用の仮想トポロジー情報。STEPの実トポロジーと別管理。

## 4. 大規模データと製品基盤

- XDEによるアセンブリー・色・名前の読込/書出し。
- 演算ワーカーと中断、プロセス隔離、クラッシュ復旧。
- 空間索引を用いた大規模形状のピッキング、表示LOD。
- Windows配布パッケージと継続的な実ブラウザーテスト。
- ブラウザー単独実行が必要になれば、WASMカーネルへ移植。ただしIGES・形状修復・メモリ上限まで同じ受入試験を通す。

各機能の完了条件は、画面が存在することではなく、適切なB-repを生成し、保存・再読込・外部メッシャーまで境界が保持されることである。
