# HyperMesh 2021との機能対応

調査日: 2026-09-16。対象はHyperMesh 2021の従来パネルにある幾何形状編集。メッシュ編集パネルのSplitとは区別する。

## 参照した公式資料

- [Surface Edit Panel](https://2021.help.altair.com/2021/hwdesktop/hm/topics/panels/help169.htm): 点・線などによる面分割、面のオフセットなど。
- [Solid Edit Panel](https://2021.help.altair.com/2021/hwdesktop/hm/topics/panels/help344.htm): 平面・面・線を使うソリッド分割、結合、ブーリアンなど。
- [Edge Edit Panel](https://2021.help.altair.com/2021/hwdesktop/hm/topics/panels/help341.htm): 自由・共有・非多様体・抑制エッジ、接続、分割解除など。
- [Solids](https://2021.help.altair.com/2021/hwdesktop/hm/topics/pre_processing/entities/solids_r.htm): ソリッドの境界種別、配置操作、形状量の確認。
- [Open CASCADE Boolean operations](https://github.com/Open-Cascade-SAS/OCCT/wiki/boolean_operations): 分割対象と工具の区別に基づくB-rep処理の基盤。

以下はGeomEditorへの設計上の対応づけであり、アルゴリズムや細部仕様の一致を示すものではない。

## 対応表

| 分類 | HyperMesh側の機能・目的 | GeomEditor初期版 | 制限・差異 |
|---|---|---|---|
| 面分割 | 点・直線に基づく切断 | 実装 | 2点と一定投影方向で工具面を作る。曲面法線追従投影は未対応 |
| 面分割 | 参照エッジに垂直な線 | 部分実装 | 直線エッジと通過点から平面を構成。対象面との交線が評価ラインになる |
| 面分割 | 線のスイープによる分割 | 部分実装 | 2点の直線のみ。延長あり/なし。曲線・スプラインのスイープは未対応 |
| 面分割 | オフセット線・複数点の曲線 | 未実装 | 任意曲面への対応には別の投影・オフセット処理が必要 |
| 面操作 | 面法線方向のオフセット | 部分実装 | 独立した新しい面として生成。選択面群の接続を維持する置換は未対応 |
| 面操作 | 延長、縮小、untrim | 未実装 | 同一曲面の分割解除だけ提供 |
| ソリッド | 平面・既存面で分割 | 実装 | 既存面は有限範囲。工具の自動延長は平面モードのみ |
| ソリッド | 線を掃引して分割 | 部分実装 | 直線の掃引による平面工具 |
| ソリッド | 結合して内部共有面を保持 | 実装 | 共有境界付き結合。任意の隙間を自動で埋める結合ではない |
| ソリッド | 和・差・共通部分 | 実装 | 選択順に対象と工具を指定 |
| ソリッド | 分離 | 部分実装 | 複数ソリッドを別ボディにする。fin faceの編集は未対応 |
| 接続 | 自由エッジを許容差内で縫合 | 実装 | 独立サーフェイス・シェルに限定。ボディ単位で実行 |
| 接続 | 任意のエッジ置換、局所切離し | 未実装 | topology mappingと局所再構成が必要 |
| 接続 | 面境界の抑制・抑制解除 | 未実装 | メッシャー固有の仮想トポロジーはSTEP出力だけでは伝達できない |
| 接続 | 同一基礎曲面の分割解除 | 部分実装 | B-repを実際に結合。選択ボディ全体が対象。必要な評価ラインも消え得る |
| 簡略化 | 穴・フィレット等を除去 | 部分実装 | ユーザーが面を選び除去・再構成。半径範囲による自動探索は未対応 |
| 形状作成 | 面抽出・穴埋め・押出し | 部分実装 | 穴埋めは閉じた平面ループ、押出しは平面フェイスのみ |
| 配置 | 平行移動・回転・倍率・鏡映 | 実装 | 倍率変更は原点基準。面単位の直接寸法編集は未対応 |
| 検査 | 接続表示・面積・体積・距離 | 実装 | 自由/共有/非多様体/周期継ぎ目を区別。抑制エッジはない |
| 管理 | 評価ラインの名前・永続追跡 | 未実装 | 現時点で面/エッジIDは編集後に更新される |
| その他 | 中立面抽出・高度な曲面編集 | 未実装 | 独立した開発対象 |

## 境界を作る意味

面に赤い線を重ねるだけではメッシャーの拘束にならない。GeomEditorの面分割はCADの面を実際に分け、ソリッド分割は内部に共有面を作る。可視化の三角形を切ってSTEPらしいものを出力する方式ではない。

HyperMeshの抑制エッジは、エッジ自体を残しながらメッシャーに無視させる仕組みである。一方、GeomEditorの「分割解除」はB-repを変更する。この2つを同一機能として扱わない。

ソリッドの水位分割と、ソリッド表面の評価ライン挿入も別操作とする。前者は複数領域、後者は元のソリッド数を保つ。
