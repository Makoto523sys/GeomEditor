# GeomEditor

**STEP / IGES のサーフェイス・ソリッドを、メッシュ作成前に編集するローカルHTMLツール。**

評価ラインを選択面の実エッジとして挿入し、水位面などでソリッドを分割します。元のCAD曲面・曲線を Open CASCADE の B-rep として保持し、編集後は STEP / IGES に出力します。解析用のメッシュ生成機能はありません。

> 初期実装です。HyperMesh 2021の形状編集を参照していますが、全機能・操作性・形状に対するロバスト性が同等になったものではありません。[機能対応表](docs/HYPERMESH_FEATURES.md)に実装範囲と未対応を記載しています。

## 起動

画面はブラウザー、形状演算は同じPC内のPythonプロセスで動作します。**HTMLファイルを単独で開く方式ではありません。GitHub Pagesへの配置だけでは動作しません。**

### Windows 11

1. Python **3.11 / 64 bit** をインストールします。
2. リポジトリをダウンロード・展開、または clone します。
3. `start.bat` を実行します。初回だけ依存ライブラリをインストールします。
4. ブラウザーで `http://127.0.0.1:8765` が開きます。

初回の依存導入後は、インターネット接続、Node.js、外部CDNは不要です。初回導入ではCadQuery/OCP等の大きなバイナリをダウンロードします。起動用の端末は開いたままにしてください。

### Linux / WSL

Python 3.11または3.12の仮想環境を推奨します。`python3 -m venv` が使える状態で以下を実行します。

```bash
bash start.sh
```

ブラウザーが自動で開かない場合は、端末に表示されるURLを開いてください。手動セットアップも可能です。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py --no-browser
```

ポート変更: `python run.py --port 8766`。起動先は常に `127.0.0.1` です。複数ユーザー向けの公開サーバーではありません。

## 主な機能

| 分野 | 実装内容 |
|---|---|
| CAD入出力 | STEP / STP / IGES / IGS読込、STEP / IGES書出し、混在するソリッド・シートの保持 |
| 作図 | 仮想節点の作成・移動、2節点を結ぶライン、節点/ライン選択、保存・Undo/Redo |
| 評価ライン | 平面の交線、2点の直線を一定方向に投影、直線エッジを基準とした平行・垂直の分割 |
| 面の分割 | 選択した面だけに実エッジを追加。ソリッド数を維持 |
| 領域の分割 | 平面または既存フェイスでボディを分割。内部共有面を保持 |
| ソリッド編集 | 和・差・共通部分、共有境界付き結合、ソリッドのボディ分離、フィレット・面取り、選択面の除去修復 |
| サーフェイス編集 | 面抽出、独立オフセット面、平面の押出し、閉じた平面ループのパッチ、縫合、閉じたシェルのソリッド化、同一曲面の分割解除 |
| 配置 | 平行移動・回転・原点基準の倍率変更・鏡映、複製 |
| 検査 | B-rep妥当性、面積・体積・最短距離、自由・共有・非多様体・周期継ぎ目の識別 |
| 作業管理 | 最大30段階のUndo/Redo、ボディ名、表示切替、B-repプロジェクト保存・復元 |

## 最初の操作例

### 水位に合わせた流体領域の分割

1. 左側のサンプルで「流体領域」を追加します（120 × 60 × 80 mmの箱）。
2. 左のモデルツリーでボディを選びます。
3. 「分割・評価ライン」→「平面で分割 / 水位面」、対象は「ボディ全体を分割」。
4. 基準点を `(0, 0, 30)` mm、法線を `(0, 0, 1)` として「分割を実行」。
5. 2ソリッドになり、Z = 30 mmの共有面ができます。体積の合計は576,000 mm³です。
6. 「書き出し」でSTEPを保存し、外部メッシャーへ渡します。共有接続をそのまま維持したい場合は補助のB-rep出力を使います。

**CAD分割だけで、あらゆるメッシャーがその水位に節点を置くことは保証できません。** CAD境界への適合、内部面・共有トポロジーの保持、節点の共有を後段で設定してください。snappyHexMeshのSTL表現や `setFields` のセル選択を通す場合は、それぞれに必要な処理が残ります。このツールは `alpha.water` の辞書も生成しません。

### ソリッドを増やさず評価ラインを入れる

1. 箱またはL形ブラケットを追加します。
2. 「対象」を「選択面だけを分割（評価ライン）」に切り替えます。
3. ビューポートで側面を選択します（複数面はCtrl + クリック）。
4. その面を横切る平面の基準点・法線を指定し、分割します。
5. ソリッド数は変わらず、選択面が複数面に分かれます。新しい線は出力CADの実エッジです。

曲面でも、工具との交線が面を分けられる場合に動作します。「2点の線」は固定ベクトル方向の投影です。任意曲面の法線に追従する投影や測地線ではありません。直線エッジに平行・垂直な操作では参照エッジを1本選択し、面分割の場合は対象面もCtrlで追加選択します。

評価ラインの幾何学的な作成と、応力線形化に適切な断面・板厚方向の選定は別の判断です。本ツールは応力分類・規格適合判定を行いません。

### 仮想節点 → ライン → 評価ライン

1. 「節点・ライン」タブで座標を入力して仮想節点を作成します。CADを読み込む前でも作成できます。
2. もう1点を作成します。モデル上をクリックした座標は「最後にクリックした点を入力」で利用できます（曲面クリックは表示近似点）。
3. 始点・終点を選択し「2節点を結ぶラインを作成」。画面または左の一覧で2節点をCtrl選択し「選択した2節点を入力」も使えます。
4. 「分割・評価ライン」→「作図ラインで分割」で作成したラインを選択します。
5. 対象を「選択面だけを分割（評価ライン）」にして対象面を選び、投影方向を指定して実行します。ソリッド全体を切る場合は「ボディ全体を分割」を選択します。

例: 流体領域サンプルの側面 X = -60 mm に Z = 30 mm の評価ラインを入れるには、N1 = (-60, -30, 30)、N2 = (-60, 30, 30) mmで作図ラインを作り、投影方向 (1, 0, 0) を指定します。

- 仮想節点は解析メッシュの節点ではなく、ワールド座標に固定した作図点です。紫の点と線は選択しやすいよう形状の手前に重ねて表示します。
- 2節点間を有限の線分として使うか、両方向へ延長して分割するかを選べます。投影方向はラインと平行にしないでください。
- 節点を移動すると接続した作図ラインが追従します。すでに分割したCAD形状は自動再計算しません。変更する場合は分割をUndoしてから再実行してください。
- 節点を削除すると、その節点につながる作図ラインも削除します。Undoでまとめて復元できます。
- 仮想節点・作図ラインは `.geomproj` に保存します。旧形式（version 1）も読めますが、新形式（version 2）は旧版アプリでは読めません。
- 作図用の点・線はSTEP/IGES/B-rep出力に混入しません。分割を実行してできたCADの評価ラインは出力に残ります。

## 操作

- 左ドラッグ: 回転。右ドラッグ / Shift + ドラッグ: 移動。ホイール: 拡大縮小。
- 「ボディ / 面 / エッジ」で選択対象を切替。Ctrl + クリックで複数選択。
- ブーリアンは選択順の先頭が対象、以降が工具です。
- 「X / Y / Z / ISO」で視点切替。`F`で全体表示、Escで選択解除。
- 「最後にクリックした点を入力」で座標入力を補助します。曲面上の点は表示近似で、端点のスナップや座標の直接入力を優先してください。
- Ctrl+Z / Ctrl+Yで元に戻す / やり直す。
- CADを追加読込すると現在のモデルに追加。プロジェクト読込は現在のモデルを置換します。
- 保存する `.geomproj` はB-repと名前・操作ログを含むZIPです。操作の再実行履歴やUndo履歴は保存しません。
- ブラウザーの再読込ではローカルサーバー内のモデルが残ります。**サーバー終了で未保存のモデルは消えます。**
- 表示を非表示にしても、書出しには全ボディを含みます。

## 単位・許容差・データ保持

- 内部単位と出力単位は **mm**。読込時にファイルの単位宣言をCADカーネルで換算します。ファイル自体の単位宣言が誤っている場合は判別できません。
- 既定の演算許容差は `1e-6 mm`。実形状の精度に合わせて変更できます（上限1 mm）。大きな許容差は意図しない境界の結合を起こし得ます。
- 表示三角形と曲線サンプルは閲覧・クリック判定専用です。CAD演算・出力は元のB-repを使います。
- 編集ごとに面・エッジIDは再生成します。選択はクリアされます。名前付き評価ラインの永続追跡は未対応です。
- STEP/IGES出力に、アセンブリー階層、色、CADのフィーチャー履歴、元の属性を完全保存する機能はありません。編集用プロジェクトは別に保存してください。
- **今回のSTEP/IGES再読込試験では、分割位置と各領域は残りますが、領域間の共有面参照は失われます。** メッシャーで共有トポロジーを再構築してください。補助出力の **B-rep** なら共有面参照を保持できます（Salome等の対応ツールで利用可能）。`.geomproj` も共有接続を保持します。
- 受け側の自動簡略化で分割線が消える場合があります。必要な評価ラインを保持する設定で再検査してください。

## 検証・制限

Pythonの形状・HTTPテスト47項目と、JavaScriptの投影・選択テスト10項目を確認しています。実行方法:

```bash
python -m unittest discover -s tests -v
# 以下は開発時のみNode.jsが必要
node --test tests/test_viewer.mjs
```

[検証記録](docs/VALIDATION.md)に対象と未検証範囲を記載しています。現環境ではクラウドブラウザーからローカルURLへの接続が遮断され、WebGLの実表示と一連のマウス操作は未検証です。Windowsでの起動も未検証です。実務形状の試験前の初期版として扱ってください。

高度なNURBS編集、任意曲面の延長・穴埋め、仮想トポロジー、任意のエッジ置換、中央値面の自動抽出などは未実装です。[開発計画](docs/ROADMAP.md)を参照してください。

## 構成

- `geomeditor/kernel.py`: CADの読込・編集・検査・書出し、トランザクション。
- `geomeditor/server.py`: 単一ユーザー向けローカルHTTP API。
- `web/`: HTML / CSS / JavaScript、依存のないWebGLビューアー。
- `tests/`: 幾何学・HTTP・投影/選択の回帰テスト。
